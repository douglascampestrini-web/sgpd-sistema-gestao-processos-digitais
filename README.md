# 🏢 SGPD — Sistema de Gestão de Processos Digitais

## 📌 Sobre o projeto

O SGPD — Sistema de Gestão de Processos Digitais — é um projeto acadêmico desenvolvido durante minha graduação em Análise e Desenvolvimento de Sistemas.

O projeto tem como objetivo propor uma solução para gerenciamento, organização e acompanhamento de processos digitais, buscando melhorar a eficiência, a organização das informações e a experiência dos usuários.

---

## 🎯 Objetivo

Desenvolver uma solução capaz de auxiliar no gerenciamento de processos digitais, permitindo maior organização, acompanhamento e controle das informações envolvidas nos processos.

---

## 👥 Público-alvo

O sistema foi pensado para usuários envolvidos no gerenciamento e acompanhamento de processos digitais.

---

## 🧩 Principais funcionalidades

- Cadastro e gerenciamento de processos
- Acompanhamento do andamento dos processos
- Organização das informações
- Consulta de processos
- Controle das etapas dos processos
- Gestão dos usuários
- Visualização das informações de forma organizada
